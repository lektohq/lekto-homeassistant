# Removal

1. Go to **Settings → Devices & services**, open **Lekto**, and select **Delete** from the
   entry's menu (⋮).
2. Open **Lekto** in the Marketplace and select **Uninstall** from its menu (⋮). While the
   integration is still set up, the Marketplace offers **Delete and uninstall**, which does both.
3. In Lekto, revoke the token in **Settings › API-Tokens**.
